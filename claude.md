## Bible quiz app

This is a bible quiz app for practicing for a bible quiz competition

# Instructions

- build a simple bible quiz app
- first page will be a landing page with a welcome message and a clickable button to begin the quiz
- The next page will be the quiz page with 50 multiple choice questions
- the quiz page will have a count down timer of 2mins 30secs that starts counting when the page loads.
- the quiz page will have a submit button at the end of the page to submit the quiz.
- The questions on the quiz page would be taken radomly between section i to section t of the pdf file "1001-Bible-Trivia-Questions-v1_00".
- The quiz automatically submits when the timer runs out
- The next page will be the results page
- The result page will show the questions answered correctly and wrongly
- For the questions answered wrongly, it will give the correct answer and scripture reference if applicable
- It will diplay the percentage score
- It will have a clickable button to go back to the landing page
- The quiz should generate 50 random and different question from section i to section t of the pdf file "1001-Bible-Trivia-Questions-v1_00" anytime users wants to retake the quiz
- Make sure proper fonts, color and styling is used
- Nothing flashy just make it simple
